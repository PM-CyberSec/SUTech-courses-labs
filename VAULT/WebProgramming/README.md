Collection of static web pages and backend scripts developed during web programming coursework, demonstrating frontend design with HTML/CSS and server-side logic with PHP.

* **Project:** Static Web UI v1.0
* **Stack:** HTML5, CSS3, JavaScript, PHP

## Project Files

Stylesheet definitions (8.3KB combined) — layout, typography, and visual design.

PHP database connection script (367B) — MySQL connection handler.

JavaScript functionality (12KB) — interactive features and DOM manipulation.
