## [ ⟁ ] LOG_01: THE CONCEPT
This repository is not a monorepo. It is a **branch-indexed portfolio vault** where every branch is an independent universe — a complete academic or technical project isolated from the rest.

* $ **ARCHITECTURE=** One branch per project. Zero cross-contamination.
* $ **MASTER_BRANCH_ROLE=** Landing page. Navigation hub. Index only.
* $ **PROJECT_ISOLATION=** Source code lives exclusively on its own branch.
* $ **DESIGN_PATTERN=** Git-as-a-portfolio. Branches as projects.

## [ ⟁ ] LOG_01.5: TELEMETRY_MIRROR

The [`VAULT/`](./VAULT/) directory is a **flat mirror** of all branches, consolidated for tooling compatibility. Language servers, dependency scanners, and CI telemetry can index every project in a single checkout without branch switching.

* $ **MIRROR_SOURCE=** Each subfolder corresponds to a branch of the same name.
* $ **AUTHORITATIVE_SOURCE=** Branches remain the single source of truth.
* $ **TELEMETRY_PURPOSE=** Enables cross-project analysis, dependency graphs, and IDE indexing.
* $ **SYNC_POLICY=** `VAULT/` is updated when new branches are added or existing branches are updated.

## [ ⌬ ] ACCESS_PROTOCOLS

* **Step 01 ->** `git clone https://github.com/PM-CyberSec/SUTech-courses-labs.git`
* **Step 02 ->** `git branch -a` *(list all available projects)*
* **Step 03 ->** `git checkout <branch-name>` *(enter a project)*

### Branches with special characters:

> The `Linux&Shell` branch contains an ampersand — **quote the branch name:**

```bash
git checkout "Linux&Shell"
```

To pull the latest state of a specific branch without switching:

```bash
git fetch origin <branch-name>
git checkout <branch-name>
```
